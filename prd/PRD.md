# 단위 변환기 — PRD (Product Requirements Document)

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 한 줄 요약 | 길이, 무게, 온도를 실시간으로 변환해주는 웹앱 |
| 문제 정의 | 단위 변환할 때 매번 검색하거나 계산기 꺼내는 게 번거로움 |
| 해결 방법 | 숫자만 입력하면 즉시 결과가 나오는 심플한 변환기 |
| 대상 사용자 | 단위 변환이 필요한 일반 사용자 (학생, 해외직구, 요리 등) |

```

│                             │
└─────────────────────────────┘
```

### 3.2 구성 요소 상세

**제목 영역:**
- "단위변환기" 텍스트
- 고정 위치, 항상 보임

**탭 바:**
- 3개 탭: 길이 / 무게 / 온도
- 현재 선택된 탭은 시각적으로 강조 (배경색 또는 밑줄)
- 기본 선택: 길이 탭
- 탭 전환 시 해당 카테고리의 기본값으로 초기화

**변환 영역 (각 탭 공통 구조):**

| 요소 | 위치 | 설명 |
|------|------|------|
| 숫자 입력 필드 | 왼쪽 | 사용자가 숫자를 입력하는 곳 |
| 왼쪽 단위 드롭다운 | 숫자 입력 아래 | 변환할 원래 단위 선택 |
| 스왑 버튼 (⇄) | 가운데 | 좌우 단위를 바꿈 |
| 변환 결과 표시 | 오른쪽 | 계산된 결과 (읽기 전용) |
| 오른쪽 단위 드롭다운 | 결과 아래 | 변환 목표 단위 선택 |

**빈 상태 / 초기 상태:**
- 숫자 입력 필드: 빈 칸, placeholder "0"
- 변환 결과: "0" 표시
- 단위: 각 카테고리별 기본값 선택됨

## 4. 지원 단위 및 기본값

### 4.1 길이

| 단위 | 표시명 | 기준(m) 대비 비율 |
|------|--------|-------------------|
| mm | 밀리미터 (mm) | 0.001 |
| cm | 센티미터 (cm) | 0.01 |
| m | 미터 (m) | 1 |
| km | 킬로미터 (km) | 1000 |
| inch | 인치 (in) | 0.0254 |
| feet | 피트 (ft) | 0.3048 |
| yard | 야드 (yd) | 0.9144 |
| mile | 마일 (mi) | 1609.344 |

- 기본 선택: 왼쪽 m / 오른쪽 cm
- 음수 허용: ❌ (0 이상만)

### 4.2 무게

| 단위 | 표시명 | 기준(g) 대비 비율 |
|------|--------|-------------------|
| mg | 밀리그램 (mg) | 0.001 |
| g | 그램 (g) | 1 |
| kg | 킬로그램 (kg) | 1000 |
| ton | 톤 (t) | 1000000 |
| oz | 온스 (oz) | 28.3495 |
| lb | 파운드 (lb) | 453.592 |

- 기본 선택: 왼쪽 kg / 오른쪽 lb
- 음수 허용: ❌ (0 이상만)

### 4.3 온도

| 단위 | 표시명 |
|------|--------|
| ℃ | 섭씨 (℃) |
| ℉ | 화씨 (℉) |
| K | 켈빈 (K) |

변환 공식:
- ℃ → ℉: (℃ × 9/5) + 32
- ℃ → K: ℃ + 273.15
- ℉ → ℃: (℉ − 32) × 5/9
- ℉ → K: (℉ − 32) × 5/9 + 273.15
- K → ℃: K − 273.15
- K → ℉: (K − 273.15) × 9/5 + 32

- 기본 선택: 왼쪽 ℃ / 오른쪽 ℉
- 음수 허용: ✅ (℃와 ℉는 음수 가능)
- K 최솟값: 0 (절대영도 이하 불가)

## 5. 사용자 흐름

### 5.1 기본 변환 흐름
1. 페이지 진입 → 길이 탭이 기본 선택됨 (m → cm)
2. 왼쪽 입력 필드에 숫자 입력
3. 입력과 동시에 오른쪽에 변환 결과 표시 (실시간)
4. 단위 드롭다운 변경 → 즉시 재계산

### 5.2 탭 전환 흐름
1. 다른 탭 클릭
2. 입력값 초기화 (빈 칸)
3. 해당 카테고리의 기본 단위 선택됨
4. 결과 "0" 표시

### 5.3 스왑 흐름
1. ⇄ 버튼 클릭
2. 왼쪽 단위 ↔ 오른쪽 단위 교체
3. 왼쪽 입력값은 유지
4. 결과 즉시 재계산

## 6. 입력 검증 규칙

| 규칙 | 동작 |
|------|------|
| 숫자와 소수점(.)만 허용 | 문자, 특수문자 입력 시 무시 (입력 안 됨) |
| 소수점 하나만 허용 | 두 번째 소수점 무시 |
| 길이/무게: 음수 불허 | 마이너스(-) 입력 무시 |
| 온도(℃, ℉): 음수 허용 | 첫 글자로만 마이너스 허용 |
| 온도(K): 0 미만 불허 | 결과가 0K 미만이면 "0" 표시 + 안내 문구 |
| 빈 입력 | 결과 "0" 표시 |
| 매우 큰 숫자 | JavaScript Number 범위 내에서 처리, 넘으면 "범위 초과" 표시 |

---

## 7. 소수점 처리

- 기본: 소수점 이하 4자리까지 표시
- 뒤쪽 불필요한 0 제거 (예: 2.5000 → 2.5, 3.1400 → 3.14)
- 정수인 경우 소수점 없이 표시 (예: 100.0000 → 100)

---

## 8. 에러/예외 처리 시나리오

| # | 시나리오 | 처리 |
|---|----------|------|
| 1 | 한글/영문 등 문자 입력 | 입력 자체를 막음 (onChange에서 필터링) |
| 2 | 같은 단위끼리 변환 (m → m) | 정상 동작, 입력값 그대로 표시 |
| 3 | 켈빈 결과가 음수 | "0" 표시 + "절대영도(0K) 이하입니다" 안내 |
| 4 | 소수점만 입력 (".") | "0."으로 처리, 결과 "0" |
| 5 | 매우 큰 숫자 입력 | Number.MAX_SAFE_INTEGER 초과 시 "범위 초과" 표시 |
| 6 | 복사-붙여넣기로 문자 포함된 값 | 붙여넣기 시에도 숫자/소수점만 필터링 |
